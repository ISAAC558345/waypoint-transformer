## 四个问题

1. 额外校准是否带来被动遥测之外的信息：否。固定校准首个间隔的名义激励积分均值为 4430.3 J，被动方法为 4562.8 J。敏感场景结束时，固定校准的平均后验方差为 0.000423，被动为 0.000616。
2. 信息是否改变任务选择：是。敏感场景里，有限前瞻与被动方法的首个服务浮标不同的配对数为 3 / 4。
3. 任务收益是否抵消校准成本：否。敏感场景上，有限前瞻减被动的净效用样本差均值为 -0.0035。这不是置信区间。
4. 决策不敏感时是否减少不必要校准：是。有限前瞻在不敏感场景的平均校准时间为 0.0 秒，敏感场景为 30.0 秒；固定校准在不敏感场景仍为 60.0 秒。
