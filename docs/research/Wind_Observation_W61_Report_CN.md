# W6.1：本机测风之后，远端报文仍降低多数飞行期误差

2026-11-15 在 W6 的冻结轨迹上给 1 号机加了点测风。A 只用本机样本，当拍可用。B 使用同一批本机样本，并在原来的到达时刻加入 0 号机的 32 字节报文。主比较是 B 减 A。C 只用远端报文，与 W6 的加权预报一致。飞行期 8 个决策里，B 比 A 低的有 9 组，只有局部场 11034 的 30 秒高 0.075 m/s。

等到达时刻的位置对照没有固定赢家。对照场和种子 11031、11032 上，0 号机的位置误差更低；11033 和 11034 上，1 号机更低。飞行中用到的四条远端样本，两机相距 1200、504.5、1089.5 和 1054 米。变好和变差的决策都覆盖这些距离。这条轨迹和四个种子不支持一条发送距离阈值。默认调度不改。

## 样本

本机测风不是调度接口。旁路在每个早发时刻读取 1 号机当时的坐标，噪声标准差仍是每个分量 0.5 m/s，两机噪声独立。同一份本机样本供 A、B 和推迟诊断使用。当拍就能进入预报，不发送，不计能耗。预报仍写在 W5.1 的外推坐标上，实际位置只用来评分。

30 个本机坐标里，29 个已经在归档场中，潜在风直接复用。只有 0 秒的 (150, 1600) 是新坐标，按局部核在全部已有场值上条件抽样，条件标准差 1.828 m/s。0 号机同时刻在 (150, 400)，相距 1200 米。评分点没有重抽，只使用远端报文的 C 与 W6 一致。

到最后一个空中决策 240 秒，B 比 A 多收 4 条报文、128 字节。整段任务的链路预算是 30 条、960 字节；其余报文在落地之后到达，不进入下面的飞行期误差。各空中决策已收到的远端报文数是 1、1、2、2、3、3、4、4。

## 复现

配置保持 `registered_before_run`，sha256 为 `3a444b4430c12b72136ed40df3ce54ca8b026e9a23a97ca2b01a139333a92115`。

```powershell
$env:PYTHONPATH = "src"
py -3 -m unittest tests.test_wind_observation_w61
py -3 -m wt.active_model_identification.run_w61
```

已有坐标被另抽一份潜在风，或各对照没有共用同一测量，就会被同一风场检查抓住。远端报文在发送当拍进入预报，或推迟样本离开远端报文的到达时刻，就会被到达检查抓住。只使用远端报文时偏离 W6，就会被基线检查抓住。
