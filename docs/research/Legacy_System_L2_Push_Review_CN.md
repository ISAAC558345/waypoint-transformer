## L3 需要解决的实际实现问题

1. `prepare.py::_graphs` 将文件写到传入output，却把图路径登记成固定L2目录。当前默认目录有效，换目录时会指回旧图。只修输出定位，并用一个新目录验证；不要重跑覆盖L2清单。
2. `row_index`、`candidate_id` 是原池编号，最大可超过128；新加载器须建立128行子集的本地位置，用分数argmax的本地位置映射真实候选和两列标签。
3. 缺失的旧 `joint_utility_encoder.pt` 是历史 `_build` 的前置依赖。随后 `phase6if/train.py` 严格加载E6完整 `model`，完全覆盖旧编码器。新隔离入口可直接构造同类HGNN、严格加载E6并加载冻结decoder，创建同参数的全新Adam，无需恢复或伪造旧encoder。该判断已有源码依据，实际strict加载和参数身份由L3验证。
4. HGNN/decoder没有Dropout，E6覆盖完整初始化，旧加载顺序固定。仅换种子0/1/2会确定性重复。因此将720更新草案缩为一次配对240更新。若以后研究训练顺序敏感性，再单独固定不同顺序；本次不追加。
