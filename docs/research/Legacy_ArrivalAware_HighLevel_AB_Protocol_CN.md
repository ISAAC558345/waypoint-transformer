# 到达感知高层方法的公平 A/B 协议

本协议只准备后续对照。本包的训练更新、环境步和策略推理都是 0，不开始训练，不重开旧 holdout，也不扫描标签权重。

## 问题

在冻结执行器上，把同一批合法候选的高层监督标签从零到达 J15 换成真实到达下的 15 步 payload 之后，所选分配是否改变。

## 唯一变量

唯一变量是离线标签来源：零到达 J15，或同一候选、同一快照上保留正式到达的 15 步 payload。候选集合、快照、冻结 MAPPO-V2、SafetyProjector、动作、奖励、G1_RATE k=6 合法池和已记录的抽样种子都保持 D5/D6 原样。E19 的 0.001 标签项不进入这个对照。

## 当前信息输入

选择时只使用决策时刻已经存在的状态，包括当前队列、当前速率、几何 ETA 和正式图里已有的特征。不读取未来到达、未来 payload、scenario_id 特征或事后最优索引。真实到达只用于生成离线标签，不写回当前观测。

## 已有数据状态

D5 的场景是 322000–322003，只检查 t=30。结论是 `ARRIVAL_AWARE_URGENCY_LABEL_COMPLETE`：零到达 J15 可以复现，真实到达改变 payload 排序。`lambda_H` 与 `delta_payload_max` 仍未定。

D6 的场景是 322016–322023，时刻是 t=0、15、30、45。结论是 `ARRIVAL_AWARE_LABEL_EXPANSION_INCONCLUSIVE`。t=0 与 t=45 的两臂标签相同；t=15 与 t=30 达到预注册的 material 标准。四个时刻没有收成一个训练目标。

两组都沿 `MAX_RATE_INDEPENDENT` 重放和冻结 MAPPO-V2 seed 0，不是 Scheme C 轨迹。两组都没有读取 validation 或 reserved test。

## 以后若获准的预算

训练和评估都先限制在 D6 已经完成的 t=15 与 t=30 标签上，不新增 rollout，不读取 322048–322079。评估只比较同一批候选的离线选择差，不跑 48 步正式闭环。这个预算尚未执行。

## 未完成的数据依赖

`delta_payload_max` 和 `lambda_H` 仍空，没有批准的 payload 损失预算。D6 的 inconclusive 结论还不能当作训练通过。完整高层训练集没有构建。`results/phase6if_ranking_loss/summary.json` 仍然缺失，不能用它补高层损失统计。E19 已经说明这条固定 0.001 标签项在 16 个状态上没有决策差，因此本协议不增大该权重。

## 判定

主结果是所选候选是否改变；若改变，再记录同一批离线标签上的 payload 差。比较成立的条件是除标签来源外没有其他改动。本协议本身不授权开始训练。
