## 诊断证据

同一批评分覆盖 E6、A10、B10 和 16 个状态。兆比特由比特除以 1e6 后保留三位小数，精确值在 `results/legacy_arrival_aware_ab_l4/group_summary.json`。

B10 的 t15 退化不只出现在两个探索状态。六个训练 t15 状态全部选出 2 架活动 UAV，所选总分都是负数。该组真实 payload 均值是 B10 18.408、A10 22.169、E6 21.881 Mbit；真实 regret 均值是 7.427、3.666、3.954 Mbit。两个探索 t15 状态更低，B10 为 14.049 Mbit，活动数分别是 2 和 1。

t15 上，边分数、活动数和较差选择一起出现。B10 训练 t15 的边矩阵均值是 -0.649，负值比例 0.972；探索 t15 的均值是 -0.672，负值比例 1。所选边的总和为负。E6 与 A10 的 t15 矩阵约有一半负值，但它们选中的边都不是负数，活动数保持为 6，加性总分约 20 到 27。匹配解码器的分数是所选边之和，idle 贡献 0；边整体为负时，少选 UAV 会使总分更高。这是同时出现的模式，不是已经证明的因果。

同活动数内的排序不能解释这次探索 t15 退化。两个探索 t15 状态在相同活动数和相同参与掩码内的真实 payload regret 都是 0，B10 已经选中该稀疏组里的真实 payload 最优候选。训练 t15 有 4/6 个状态在同活动数内仍有正 regret，但同掩码 regret 只在 1/6 个状态出现。因此探索 t15 的主要差距是跨活动数选择，不是该掩码内部排错。t30 上三份模型都有同活动数 regret，这项误差不是 B10 的 t15 独有现象。

t30 有同方向、但程度不同的分数下移。E6 的 t30 矩阵均值约为 +3，负值比例为 0；B10 的训练和探索 t30 均值约为 +0.033 和 +0.011，负值比例约为 0.39。B10 选中的边仍全部非负，活动数是 5.67 和 6，没有出现 t15 的一到两架稀疏选择。现有证据支持 t30 分数也向下移动，不支持“t30 矩阵没有变化”。现有证据也不足以把 t30 的移动说成与 t15 相同强度的同一机制。

按同一真实到达目标比较 KL，B10 在四个分组都低于 A10 和 E6。训练 t15 的真实标签 KL 是 B10 3.267、A10 11.479、E6 9.183；探索 t15 是 2.458、5.107、4.090。B10 对零到达目标的 KL 则高于 A10。因此“最终 checkpoint 没有靠近真实到达软目标”不被支持。argmax 真实 payload 是另一个读数：B10 在训练 t15 已经比 A10 和 E6 差。L3 第 10 轮更新前的在线损失均值是 A 3.627、B 4.710，这是不同目标熵下的过程记录，不能用来判断最终选择。

真实到达目标自己的期望活动数在训练 t15 约为 3.93，B10 的模型概率期望活动数约为 4.00，但 argmax 选的是 2。探索 t15 的目标期望活动数约为 5.07，argmax 却是 1.5。软目标拟合和加性 argmax 选择并不一致。16 个状态不能说明这个结构不可能学习到达信息。
