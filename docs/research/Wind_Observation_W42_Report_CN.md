# W4.2：两机同时回传时，首包晚 82.613 秒

2026-11-15 复用 W4.1 的逆风种子 1103、240 秒快照和及时组轨迹。报价仍假设 0 号机等待，于是把 3 号浮标首包写成 253.645 秒；实际是 336.258 秒。差值 82.613 秒可以拆成两段：两机按回传脚本继续时晚 22.613 秒，随后两次返航把队列停住 60.000 秒。残差是 0。到岸时刻没有进入分数。

把同一条后续规则用到两机同时回传上，1 号机的 0.95 分位末端电量从 5227.488 J 降到 −143.945 J，回传不再准入，这一拍的选择改成返航。从该状态按这个新选择补跑一次闭环，按时 bit 和备用不变，全队多耗 212.468 J。不推荐扩大验证，默认调度不改。

## 240 秒之后的链路

两机缓存都是 70000 bit，各自按包计算需要 17.020 秒链路。执行器每个秒里先给 0 号机。指令和遥测另占 0.479 秒，不计入下面的业务链路。

| 时段 | 执行 | 0 号机获得 | 1 号机获得 | 1 号机发出 | 3 号浮标剩余 |
| --- | --- | ---: | ---: | ---: | --- |
| 240–270 秒 | 两机回传 | 17.020 秒，70000 bit | 6.052 秒 | 24800 bit | 首包 20200 bit，次包 25000 bit |
| 270–330 秒 | 两机返航 | 0 | 0 | 0 | 不变 |
| 330–360 秒 | 1 号机回传 | 0 | 10.968 秒 | 45200 bit | 两包到岸 |

0 号机在这一拍把缓存发完，四包到岸时刻是 242.897、245.897、253.645、261.645 秒。后两个时刻就是另机等待时报价写给 1 号机 3 号浮标的时刻：独占链路的时间表被排在前面的 0 号机用掉了。1 号机的两包 2 号浮标在 264.897 和 267.897 秒到岸，比独占时间表晚 22.000 秒。发完的缓存在按包计时后与获得的链路时间一致。270 到 330 秒队列没有变化。

330 秒 1 号机单独恢复回传，剩余两包需要并获得 10.968 秒。首包在 336.258 秒、次包在 344.258 秒到岸，送达者都是 1 号机。从 330 秒起用了 6.258 秒和 14.258 秒。若 270 秒不转去返航、而按回传脚本继续，首包会在 276.258 秒到岸，距离 270 秒同样是 6.258 秒。

## 决策时可算的两种预测

这一拍两机的请求在推进之前就由同一策略算出，0 号机请求的就是回传。区分“另机等待”和“这一拍同时回传”不需要另发一条无线电。270 秒以后的请求这时还没有产生；下面持续到交付的联合脚本，是把已登记的回传脚本同时用在两机上，不是已知的未来动作。真风和归档动作只用于核对。

只看下一次重选前的 30 秒，风和能耗系数用决策时的报文均值与信念均值：

| 0 号机 | 1 号机按时 bit | 3 号浮标到岸 | 两机耗电 J |
| --- | ---: | --- | --- |
| 等待 | 70000 | 253.645、261.645 秒 | 4212.875、5272.615 |
| 回传 | 20000 | 这一拍未到岸，剩余 20200 和 25000 bit | 4214.448、5271.601 |

同时回传的队列与归档执行一致。归档在真风和真系数下的耗电是 4220.352 J 和 5230.578 J，与信念均值预测相差 5.904 J 和 41.023 J。30 秒里的耗电几乎不随另机是否回传而变。

把脚本继续到交付：另机等待时，两包仍是 253.645 和 261.645 秒，70000 bit，报价耗电 13242.582 J，0.95 分位末端 5227.488 J，准入。两机都按回传脚本继续时，两包是 276.258 和 284.258 秒，按时 bit 仍是 70000，报价耗电升到 18530.204 J，末端降到 −143.945 J，不再准入。返航报价不变，末端 10558.425 J，分数 −0.022208。原调度这一拍仍然请求返航，所以新的选择是返航，原因是 `tie_scheduler`。到岸时刻没有参加这次重算。

首包的 82.613 秒因此是 22.613 秒加 60.000 秒。22.613 秒是共享链路下把回传脚本进行到底的推迟，60.000 秒是 270 和 300 秒两次返航。次包同样是 22.613 秒加 60.000 秒，实际 344.258 秒。两项之和与归档差值的差是 0。

## 改选返航的一次闭环

新选择只在 240 秒替换 1 号机的请求，之后仍用 W4 的规则。结果与 W4.1 里同一报文、首动作为返航的那一格相同：140000 bit，两机都返航并保持 4000 J，全队 119222.271 J，净效用 13.668827。相对及时组的回传基线 119009.803 J 和 13.669417，多耗 212.468 J，净效用少 0.000590。3 号浮标改在 283.645 和 291.645 秒由 1 号机送到，比 336.258 秒早 52.613 秒。按时交付和备用没有收益，能耗和净效用退步。不据此扩大场景，也不改默认调度。
