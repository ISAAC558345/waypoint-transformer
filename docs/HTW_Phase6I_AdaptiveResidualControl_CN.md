# Phase-6I-M：受限自适应残差轨迹控制

正式低层仍然是冻结的 `phase6g_seed0.pt`，SHA-256 为 `92aa68785c898415439ad8c6480427593e10c851e3d392ee3a8110f3a58dbd0e`。训练结束后该文件的哈希没有变化。Phase-6I-K 和 Phase-6I-L 的 checkpoint 没有被加载，也没有被覆盖。直接速度实验的权重没有接入。高层方案 C Epoch 1、G1_RATE k=6、hold=15、环境动力学、队列计账、TaskOption 和 SafetyProjector 的安全边界都没有改。没有读取 322064–322079，也没有改 `FormalPlanner`。

第一轮没有稳定提高实际交付量。安全违反率没有高于冻结策略。按本阶段的判据，不替换当前低层，也不做转向、速度和投影的第二轮消融。

## 1. 动作映射

新模块在 `src/wt/benchmark_v2/phase6im_adaptive_residual/`。Actor 仍是原来的二维 `ResidualActor`，输入维度不变，初始权重来自 `phase6g_seed0.pt`。Critic 的第一层宽度与 `expected_critic_dim(6, 12)` 一致，因此复用了原 Critic。奖励仍是 Phase-6G 的 `low_level_reward`：交付项 `served_bits / 1e6`，投影惩罚系数 0.05，残差惩罚系数 0.01。残差项作用在 `command - fly_toward` 上，不再惩罚整条速度。

两个输出的含义和冻结残差不同。冻结残差把两个分量加到世界坐标的 `fly_toward` 上。这一轮把它们解释成极坐标：

- 维度 1 是相对 `fly_toward` 的转向，正角为逆时针，截断在 ±45°。
- 维度 2 是速度比例，0 到 1，对应 0–22 m/步。
- 转向后的方向乘以速度，再经过原来的 `clip_unit_step`。
- 目标方向为零、输入非有限、或温度非正时，命令为零，也就是悬停。

±45° 和 0–22 m/s 只写在实验配置 `results/phase6im_adaptive_residual/config.json`，其中 `official_config` 为 false。正式配置没有这些数。

旧权重不是按这个极坐标训练的。标定使用 321000–321007 上冻结 actor 的确定性均值，共 1437 个有目标的无人机步，滚动时仍走原来的残差命令和原来的 SafetyProjector。测到的分布是：

| 量 | 数值 |
| --- | --- |
| 旧输出维度 1 的中位数 / 标准差 | 0.326 / 0.114 |
| 旧输出维度 2 的中位数 / 标准差 | 0.234 / 0.085 |
| 旧命令相对目标方向的偏角中位数 | 2.950° |
| 旧命令速度中位数 | 1.0 |
| 转向中心 / 温度 | 0.326 / 1.0 |
| 速度偏置 | 1.712 |
| 新映射初始偏角中位数 / 90 分位 | 2.008° / 10.247° |
| 新映射初始速度中位数 | 0.98 |

旧速度中位数是 1，因为单位目标加上小残差后会被截断到满步。速度头把中位数映到 0.98，是为了避免 `tanh` 钉死，使策略以后还能减速。这只对齐了中位数。旧的两个分量仍是世界坐标残差，会随目标方向改变落点；新映射把同一对输出当成转向和速度，状态条件上的小修正对不上。

确定性测试确认了 +45° 为逆时针、-45° 为顺时针、速度落在 [0, 1]、零目标和 NaN 变为悬停、环境坐标轴上的 22 m 位移、计账误差在容差内、assignment 不被动作改写，以及间距小于 1 m 时投影仍把无人机分开。`d_safe` 仍是 1.0 m，服务内半径仍是 15.5 m。3 个测试通过。

开发集 smoke 使用方案 C，场景 321096。episode 完整，payload 61587237.195 bit，命令偏角 1.743°，执行偏角 1.745°，单步不超过 22 m，安全违反率为 0，决策 4 次。训练池 smoke 使用 321000，计账通过，安全通过，单步最大 21.620 m。

## 4. 判断

未训练的极坐标映射已经比冻结残差少大约 7.75e6 bit，区间整体为负。中位数上它仍接近直线趋近，所以差距不是因为初始策略突然转了 45°。旧 actor 的两个输出是世界坐标残差；把它们重新解释成转向和速度，保留了“大约 2°、接近满速”的中心行为，但换掉了原来随目标方向变化的小修正。

训练没有把这个差距补成稳定收益。评估时的平均转向只有 2.7–3.8°，执行方向紧跟命令，投影修正量大约 0.02。安全约束没有变松，也没有明显恶化。因此这一轮的负结果不能解释成“SafetyProjector 把新轨迹抵消了”。±45° 的权限在奖励和当前 80 次更新下没有被用上。

正式执行继续使用冻结残差 MAPPO。下面三份权重只留在实验目录。
