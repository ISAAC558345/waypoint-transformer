# Round-35 Working Rules

Round-35 is a **Level-2 Relational Multi-UAV Benchmark Environment
Implementation and Structural Validation** round.  It may implement only the
M=4, K=8, T=20 shared-spectrum Level-2 environment, an external association
preference action, exact structured feasibility decoding, generated
engineering scenarios, and non-learning structural validations.

The locked Round-19 movement, queue, energy, safety, shared-spectrum physics,
and reward equations remain unchanged. `legacy_deterministic` must delegate
exactly to the historical matching path. `external_preference` may use physical
values only for a current candidate mask and consequences; its selection
objective is supplied `A_assoc`, never the old queue/rate heuristic.

Training, model inference, optimizers, backward passes, HGNN/DeepSets/
Task-Waypoint/Transformer/PPO/BC/predictor work, planners or triggers,
reward/physics redesign, new physical action channels, dynamic channels,
buoy drift, Level-3, and Round-36 are prohibited.

No protected data may be decoded. Round-35 accepts only generated
`round35_level2_engineering_v1` metadata and fail-closes before decoding any
unknown, development, test, fresh, or untouched provenance. A second protected
decode, historical-lock mutation, legacy exact-regression failure, or
unfixable decoder constraint violation is an immediate stop condition.

All new artifacts belong in `round_35`; completed-round evidence is immutable.
