## 1. 势函数

只对当前分配了目标的 UAV 取平均。空闲分配 `association < 0` 不进入平均。距离、服务半径和归一化长度都来自环境配置，单位是米：

```text
distance_norm_m = step_length_m = 22
service_radius_m = 16
Phi(s) = -mean_active( max(distance_m - 16, 0) / 22 )
F(s, a, s_next) = 0.99 * Phi(s_next) - Phi(s)
```

`0.99` 是当前 MAPPO 的 `PPO.gamma`。半径内超出距离为 0，所以 `Phi` 不奖励继续靠近浮标中心，也不读取 `served_bits`、`payload_bits` 或 `q_bits`。终止步把下一状态势函数写成 0。原始任务奖励保持

```text
served_bits / 1e6 - 0.05 * c_project - 0.01 * c_residual
```

训练回报是这两项之和。势函数只依赖当前可观测位置和当前分配。在折扣目标下，终止势函数为 0 的势函数塑形不改变原始回报的最优策略；80 次 PPO 更新不是精确最优，所以实际 payload 仍可能变化。成功与否只看开发验证上的实际交付量。

确定性检查用场景种子 321000 摆好位置，3 个测试通过：

| 情形 | 结果 |
| --- | --- |
| 一个目标步之外，再靠近半步 | `Phi` 从 -1 升到 -0.5，`F = 0.505` |
| 同一位置再远离一步 | `Phi` 降到 -2，`F = -0.980` |
| 已在半径内，并继续靠近中心 | `Phi = 0`，`F = 0` |
| 全部空闲，或只移动空闲 UAV | `Phi = 0`；空闲位移相对停留的 `F` 增量为 0 |
| 终止，即使传入的下一势函数是 -4 | 超出一步时 `F = 1`；半径内终止时 `F = 0` |
| 把 payload 改成 5e7、把队列改成常数 | `Phi` 不变 |

因此空闲 UAV 不会因为自己的位移得到额外塑形。正在交付的比特只出现在原始任务奖励里。

## 2. 训练配置

Actor 从 `phase6g_seed0.pt` 严格加载，梯度打开。输入宽度没有变化。Critic 第一层宽度与 `expected_critic_dim(6, 12)` 一致，复用了同一份 Critic。评估动作仍是确定性均值、`alpha=0.25`、`fly_toward` 加残差、单位步截断和原来的 SafetyProjector。塑形不进入评估时的动作选择；评估轨迹上的 `F` 只作为分项记录。

训练场景是 321000–321095。采样器仍是原来的合法 G1_RATE k=5、hold=15。评估是方案 C 的完整 episode，场景 321096–321127，这 32 个场景不在训练池里。模型种子 0、1、2，各 80 次更新。判定规则在看结果之前写定：至少两个 seed 的平均 payload 差为正、bootstrap 95% 区间下界为正、安全违反率不超过基线加 0.02、没有不完整 episode，并且最大正场景不超过正差总和的一半或去掉该场景后平均差仍为正。Bootstrap 10000 次，种子 0。

Smoke test 跑完一个 48 步 episode：自身观测维 5，动作预激活维 2，`alpha=0.25`，计账通过，SafetyProjector 仍是原投影器。该 episode 的任务奖励总和是 73.614，塑形总和是 6.721，总奖励等于两项之和。

## 4. 判断

势函数方向、空闲 UAV、半径内、终止状态和比特隔离都符合设计。原始任务奖励仍在，安全边界没有放宽。开发验证上的实际交付没有可靠提高，seed 1 明显下降。本阶段不替换正式低层，也不再改塑形系数或叠加第二种奖励。
