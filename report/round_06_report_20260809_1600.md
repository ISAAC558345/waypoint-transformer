# Round-6: frozen-model paired closed-loop evaluation

Round-6 evaluated, and did not train, the locked Round-4 H=30
goal-conditioned Waypoint Network and all three saved seeds of six Round-5
deployable policies. The environment remains the existing single-UAV/static-
buoy queueing task. No PPO, HGNN, multi-UAV, drift, resource action, or
checkpoint was created.

## Protocol

The formal set is 30 new scenario seeds (`1000..1029`) times existing 3/5
buoy scales: 60 physical scenarios. These are disjoint from Round-3's `0..9`
train/validation/test seeds. Each scenario has one materialized arrival trace
and deterministic snapshot. Each of the four frozen non-learning policies
first supplies a reference trajectory; its achieved terminal 13-D goal is
frozen before every tested rollout. All tested models start from the same
snapshot and receive the same fixed reference goal. No reference future
state/action and no tested-policy future result is used by inference.

WT recomputes the H=30 waypoint every step, builds causal Hc=10/Hc=1 history
from evaluated-policy observations, uses the common unit-disk projection, and
calls `env.step` exactly once. Direct-Goal receives the reference goal but no
waypoint; State-only receives neither. Oracle is excluded from ranking.

## Main paired result

WT Hc=10 mean return/payload are 35.198 / 157.169 Mbit; Direct-Goal Hc=10
has 35.288 / 159.862 Mbit. Bootstrap resampling unit is scenario (not
transition):

| Metric (WT minus Direct) | Mean | 95% bootstrap CI |
| --- | ---: | ---: |
| Payload | -2.693 Mbit | [-6.276, +1.045] Mbit |
| Return | -0.091 | [-0.934, +0.769] |

Both primary CIs cross zero and model-seed rankings are not stable. Hc=10
does not retain its offline Hc=1 return/payload advantage, although Hc=10 has
lower mean final goal error (0.644 versus 1.100). Waypoint/action error
correlations are weak (0.081 for WT Hc=10; 0.119 for Hc=1). The normalized
training-state distance is modest: 0.891 WT Hc=10, 0.928 Direct-Goal and
0.995 State-only.

## Decision

RQ1–RQ5 do not establish a closed-loop Waypoint gain. Offline action RMSE does
not imply communication advantage here; there is neither strong error
compounding nor a conspicuous rollout OOD failure explaining the result.

**Gate B — no reliable closed-loop Waypoint difference.** Do not start
HGNN/multi-UAV/drift expansion. If a later round is authorized, first improve
low-quality/noisy trajectory coverage and stitching, re-check the goal
definition, and analyse waypoint horizon/multimodality before retraining.
