# Round-11 task-aware communication Waypoint Network report

## Scope and isolation

Round-11 trained only a shared MLP on the locked Round-10 task-waypoint
samples.  Its input is `[observable_state, buoy_mask]`; variable state widths
are zero-padded to the largest width in the permitted sample package (44),
and the separate mask has width 5.  No goal fields, difficulty, quality,
behavior-generator metadata, spatial target, action, future observation,
policy, Transformer, or closed-loop interface is used.

Only Round-10 `train` and `validation` rows were accepted by the loader.
The isolation audit records zero old-development-test and untouched-holdout
content accesses.  The H-step return uses gamma=0.99.  The gross progress
target is actual future-window transmitted payload, not net queue decrease;
net progress remains diagnostic only.

## Architecture and normalization

The model is exactly three `Linear(256) + ReLU` trunk layers, dropout 0, with
three dynamic-width heads: masked service softmax over `Nmax`, non-negative
gross service progress, and scalar discounted H-step return.  Progress is
normalized by the configuration-derived `queue_capacity_bits=5,000,000` and
uses `softplus`: an H-step cumulative payload is not generally bounded by one
queue capacity, so sigmoid would impose a false upper bound. Return is
standardized with train-only mean/std per horizon. Padding is removed before
every service or progress loss reduction.

## Training and validation

Six runs were made: H=10 and H=20, seeds 0/1/2, Adam lr=0.001, batch=256,
weight decay=0, gradient clipping=1, at most 300 epochs, validation every five
epochs, and patience of 30 validation checks. Checkpoint selection is minimum
validation total loss and the per-head checkpoint guard passed for all seeds
at both horizons. All recorded gradient norms were finite.

| Horizon | Validation total loss, mean | Service CE gain vs train mean | Progress MSE gain | Return MSE gain |
|---|---:|---:|---:|---:|
| H=10 | 1.5793 | 1.98% | 47.63% | 85.72% |
| H=20 | 1.6252 | 1.72% | 51.40% | 88.04% |

H=10 is recommended because its mean validation total loss is lower. The
predictor gate is **TW-A**: all three heads improve over the train-mean
baseline across all H=10 seeds. This is a supervised predictor result only;
it does not establish an improved closed-loop policy.

## Remaining limitations

The source data has no variable episode task-goal field and no available
difficulty/quality metadata. The H=10 service-distribution gain is modest,
although it is consistent across seeds. Future work requires separate
authorization and must not infer closed-loop usefulness from this report.
