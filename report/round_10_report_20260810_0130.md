queues, arrivals, actual per-buoy payload and communication reward semantics.

is zero; the observed data had no no-service windows.  Queue audit retains both
net progress and gross actual service, recommends gross service because it is
arrival-robust and physically direct, and validates conservation.  The return
head recommendation is H-step discounted return (H=20), while remaining return
is retained as a diagnostic.

M3 found spatial-only Waypoints unhelpful.  H=20 is recommended; H=10 remains
stored for a later authorized comparison.  Training readiness is true for the
label semantics, masks, conservation, sample counts and isolation, while the
absence of difficulty/quality sidecars in the development-only files is
recorded as a reporting limitation, not repaired by reading holdout content.
